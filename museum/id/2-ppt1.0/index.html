Forethought PowerPoint

对，这就是最早的PPT，最开始这不是微软开发的！

软件发布于1987年2月22日，是Macintosh独占的软件。

软件发布4天后，微软就报价530万美元打算收购，但是好巧不巧，苹果（Apple），宝兰（Borland），施乐（Xerox）也看好，报价甚至是微软的3倍，但是6月微软还是以1400万美元收购了Forethought（这也是微软的第一次收购）。

它的创建者罗伯特·加斯金斯（Robert Gaskins，前Forethought高管），也在收购后成立微软图形业务部负责人。

PPT以“人人都能制作幻灯片”为初衷，尽管它的出现的也带来许多社会性危害，并且被乔布斯和其他组织公司高管所嫌弃，但是依旧阻挡不了其发扬光大（实际上开发者是同意这些抱怨的，但他们认为大众不公平地把矛头指向了软件，而不是使用该软件进行偷懒、制作糟糕演示的人。“这就像印刷机。它可以印刷各种垃圾。”）。

软件最开始是叫Presenter（演示者），但后面因为商标被占用，才换成PowerPoint的（该名字的出现也是一时的灵感）。

现在它是Office三件套的其中一位，并早在微软收购后就推出了Windows版本。
